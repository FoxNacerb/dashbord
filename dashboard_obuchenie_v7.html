Вход в админ-панель

Требуется авторизация для управления данными.

Админ-панель

1. Скачать шаблон Excel

Шаблон содержит два листа: «Данные» (сводка по темам) и «Сотрудники» (детализация).

2. Загрузить новый файл

Выберите заполненный Excel. Данные заменят текущие.

3. Сбросить данные

Вернуть демонстрационные данные по умолчанию.
